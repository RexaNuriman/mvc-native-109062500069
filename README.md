# Aplikasi CRUD Data Film

Aplikasi web untuk mengelola data film menggunakan PHP Native dengan pola arsitektur Model-View-Controller (MVC).

## Teknologi
- PHP Native
- MySQL/MariaDB
- PDO
- Git dan GitHub

## Fitur
- Create: menambahkan data film
- Read: menampilkan data film
- Update: mengubah data film
- Delete: menghapus data film

## Status Pengembangan
Tahap awal: inisialisasi proyek dan persiapan struktur MVC.
